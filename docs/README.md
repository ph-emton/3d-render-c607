# Project Documentation & Resources

Reference documentation and design resources for Apartment C-607 interior execution.

## Files

1. **`prompt generation.md`**:
   - The "Golden Trio" workflow for turning 3D planner screenshots into photorealistic interior renders using Gemini / Imagen 3.
   - Includes tailored, ready-to-copy architectural prompts for each room (Brother's room, Your room, Living/Dining Hall, Kitchen).
2. **`OPTION_B_IMPLEMENTATION_PLAN.md`**:
   - Technical architecture and design specification for the Three.js glTF 3D models pipeline, asset bundling, and performance optimizations.
