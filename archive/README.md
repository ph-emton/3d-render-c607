# Archive Directory

This directory contains earlier prototype versions and historical snapshots of the C-607 interior planner.

## Archived Files

1. **`C607 interior planner.html`** (v1):
   - The initial 2D floor planner and basic procedural 3D box model view.
2. **`C607 interior planner realistic.html`** (v2):
   - Procedural realistic textures, contact shadows, and early lighting experimentation.
3. **`C607 interior planner 3d models.html`** (v3):
   - Pre-deployment version of the 3D glTF models planner (now superseded by root `index.html`).

> **Note**: For all ongoing development, refinements, and live viewing on GitHub Pages, use **`index.html`** in the repository root.
