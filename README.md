# C607 3D Interior Planner & Photorealistic glTF Visualizer

Interactive architectural 3D interior design and space-planning tool for Apartment C-607, powered by Three.js and real-time glTF 3D models.

## Live Demo (GitHub Pages)
Once GitHub Pages is enabled in repository settings, the live interactive planner is available at:
👉 **`https://ph-emton.github.io/3d-render-c607/`**

---

## Key Features

- **Photorealistic 3D glTF Models**: Real beds, sofas, study desks, wardrobes, appliances, and fixtures.
- **Walk (POV) Mode**: First-person walkthrough at human eye level with WASD/arrow keys and mouse look.
- **Ultra-Wide Field of View**: Support for 30° to 125° FOV with quick chips for **105° Ultra-Wide** and **115° Panoramic** perspectives.
- **Per-Room Wall Painting**:
  - Independent wall paint selection for each room (Hall, Your room, Brother's room, Kitchen, Utility, Balcony, Toilets).
  - Multi-material 3D wall face mapping with Asian Paints Royale palette and custom color pickers.
  - "Current Room" auto-detection in Walk POV mode.
- **2D Floor Plan Editor**: Interactive SVG plan view with drag-and-drop placement, rotation, snapping, and dimension lines.
- **Carpentry Scope & Cost Estimator**: Automatic calculation of front surface area (sft) and loose furniture breakdown.
- **JSON Import / Export**: Share and restore complete room layouts.

## Enabling GitHub Pages

1. Go to your repository on GitHub: [https://github.com/ph-emton/3d-render-c607](https://github.com/ph-emton/3d-render-c607)
2. Click **Settings** (top tab) → **Pages** (left sidebar).
3. Under **Build and deployment** > **Branch**:
   - Source: `Deploy from a branch`
   - Branch: `main` / `root`
4. Click **Save**.
5. After ~1 minute, your site will be live at:
   `https://ph-emton.github.io/3d-render-c607/`
